# Практика программирования
Данный репозиторий содержит программу на языке C++ для отчёта по предмету «Практикум по программированию».

## Описание программы
Программа сравнивает сортировку "Пузырьком" и сортировку "Выбором" по количеству сравнений и перестановок (обменов) при работе с массивами разных размеров.
